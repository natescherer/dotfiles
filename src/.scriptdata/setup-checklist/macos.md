# macOS Setup Checklist

Manual steps that the Ansible playbook can't handle by itself. Check items off as you go — this
file is only written once.

## Manual Installs

- [ ] [VMware Fusion](https://archive.org/download/vmwareworkstationarchive/)
- [ ] [Home Printer Drivers](https://epson.com/Support/Printers/All-In-Ones/ET-Series/Epson-ET-8500/s/SPT_C11CJ20201)

## Settings

### Settings.app

- **Wi-FI**
  - [ ] Turn off Private Wi-Fi address for home network
- **Bluetooth**
  - [ ] Pair devices
- **General**
  - **Date & Time**
    - [ ] Enable `Set time zone automatically using current location`
- **Menu Bar**:
  - [ ] Enable `Show menu bar background`
  - **Menu Bar Controls**
    - [ ] Disable `Spotlight`
    - [ ] Enable `Wi-Fi`
    - [ ] Disable `Battery`
    - [ ] Disable `Focus`
    - [ ] Disable `Screen Mirroring`
    - [ ] Disable `Display`
    - [ ] `Sound` to `Always Show`
    - [ ] Disable `Now Playing`
    - [ ] Disable `Timer`
- **Touch ID & Password**
  - [ ] Enroll a fingerprint.

### Finder

- **Sidebar**
  - [ ] Uncheck `Shared`,
  - [ ] Uncheck `iCloud Drive`
  - [ ] Uncheck `AirDrop`
  - [ ] Uncheck `Bonjour computers`
  - [ ] Uncheck `Connected servers`
