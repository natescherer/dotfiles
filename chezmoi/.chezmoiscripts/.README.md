# Script Folders

This file is named `.README.md`, not `README.md`, because chezmoi treats every
file in this folder as a script. A plain `README.md` makes `chezmoi apply` fail
with "not a script", even when `.chezmoiignore` lists it; chezmoi skips files
whose names start with a dot.

Each folder is named `<order>-<platform>[-<scope>]`. The ignore template
matches these names with one pattern per platform and per scope, so a script
placed in the right folder needs no ignore rule of its own.

## Order

chezmoi runs scripts in the alphabetical order of their paths, so the number
sets when a folder's scripts run. Within a number, `<n>-<platform>` sorts
before `<n>-<platform>-<scope>`. When a scoped folder has to run first, give it
a lower number instead: Ansible installs the tools that the dependency checker
looks for, so `10-ubuntu-osconfig` runs before `11-linux`.

## Platform

| Platform | Runs on |
| --- | --- |
| `all` | Every machine |
| `posix` | Linux and macOS |
| `linux` | Linux, NixOS included |
| `ubuntu` | Ubuntu 26.04 desktops |
| `macos` | macOS |
| `windows` | Windows |

## Scope

| Scope | Runs when |
| --- | --- |
| *(none)* | Always, on that platform |
| `workstation` | The machine is a workstation (`isWorkstation`) |
| `osconfig` | The machine is a workstation that applies this repo's OS configuration (`applyOSConfig`) |

Devcontainers run no scripts at all. A script that also depends on another
answer, such as `isPersonal` or `adminRights`, still needs its own ignore rule.

## Renaming

chezmoi tracks a `run_onchange_` script by its path as well as its contents,
so moving one to another folder runs it again at the next apply. A `run_once_`
script is tracked by its contents alone and doesn't run again.
